DECO / Interactive Prototype

GuideWay

A clickable web prototype for visually impaired pedestrian navigation with rear-camera preview, scanning overlay, graded obstacle alerts, browser voice prompts, and vibration feedback fallback.

Best testing setup:
Open on a phone browser with camera permission enabled. HTTPS is recommended for live camera access.

Prototype Features

  • Clickable page transitions
  • Device connection screen
  • Phone rear camera preview on Navigation page
  • Scanning animation overlay
  • Distance recognition card
  • Near / medium / far obstacle simulation
  • Voice prompt using browser speech synthesis
  • Vibration API with visual buzz fallback

Interaction Flow

  1. Starting Situation
  2. System Activation
  3. Environment Detection
  4. Feedback Triggered
  5. User Reaction
  6. Safe Continuation

Testing Notes

On some browsers, physical vibration or speech playback can be limited. The prototype will still show a visual buzz fallback and clear alert states during demos.
